# MITRE ATT&CK --- T1059.001 PowerShell

## Technique

**T1059.001 --- PowerShell**

**Tactic:** Execution

## Lab Evidence

The controlled test executed:

``` powershell
powershell.exe -Command "Write-Host 'SOC LAB TEST'"
```

Wazuh mapped the resulting Sysmon Event ID 1 alert to T1059.001.

## Why It Matters

PowerShell is a legitimate Windows administration and automation tool.
In security monitoring, PowerShell activity is therefore investigated
based on context rather than automatically classified as malicious.

Relevant context includes:

-   Command line
-   Parent process
-   User
-   Integrity level
-   Executable path
-   Hash
-   Network connections
-   Child processes
-   File creation
-   Other events around the same timestamp
