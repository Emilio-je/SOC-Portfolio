# Evidence

Store screenshots and exported evidence from the lab here.

Recommended evidence:

-   Wazuh agent connected/active
-   Sysmon service running
-   Sysmon Event ID 1
-   Wazuh alert for Rule 92027
-   Alert details showing command line and parent process
-   MITRE ATT&CK mapping

## Security

Never store:

-   Passwords
-   API keys
-   Tokens
-   Private keys
-   Authentication cookies
-   Personal credentials
